# Setup Guides

Work through these **in order** before trying any of the experiments. Each one builds on the last.

| Step | File | What it covers |
|------|------|---------------|
| 1 | [1-raspberry-pi-ssh-setup.md](1-raspberry-pi-ssh-setup.md) | Flash Raspberry Pi OS, register on Fermilab wifi, SSH in |
| 2 | [2-openplc-runtime-setup.md](2-openplc-runtime-setup.md) | Install OpenPLC Runtime on the Pi, install the Editor on your computer |
| 3 | [3-example-raspberry-pi-plc.md](3-example-raspberry-pi-plc.md) | Wire a button + LED, write ladder logic, upload and run it |

Once you can run the example in step 3, you're good to move on to the [experiments/](../experiments/) folder.
