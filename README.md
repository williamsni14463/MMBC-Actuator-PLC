# MMBC-PLC-Setup-&-Testing

This repository covers the steps to create a Programmable Logic Controller from a Raspberry Pi and an opensource program called OpenPLC.

Additionally, it includes a few guided tutorials for different applications of a raspberry pi PLC.

The files beginning with RND are my documented steps for the different experiments I've been working on, including my troubleshooting and results.

Work through files 1-3 for initial setup.
